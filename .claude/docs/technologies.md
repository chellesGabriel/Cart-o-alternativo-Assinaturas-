# Tecnologias

| Tecnologia | Uso |
|------------|-----|
| pnpm | Gerenciador de pacotes. |
| React 19 | Framework principal. |
| TypeScript 6 | Tipagem obrigatória em todo o projeto (strict) |
| Vite 8 | Build e dev server. |
| Ant Design 6 | Componentes de UI (form, table, modal, input, select, feedback). |
| Tailwind CSS 4 | Layout, espaçamento, tipografia e responsividade. |
| Zustand 5 | Estado global do cliente (sessão, preferências). |
| React Router 7 | Roteamento. |
| Lucide React | Ícones. |
| ESLint + Prettier | Lint e formatação. |
